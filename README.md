# pyOpenTube
A minimalist, open-source YouTube clone built entirely in vanilla Python. No frameworks, no pip install, no dependencies. Just one file.

---

## 🚀 Installation & Setup

```bash
git clone https://github.com/mrushchyshyn/pyOpenTube.git
cd pyOpenTube
python3 app.py
```
